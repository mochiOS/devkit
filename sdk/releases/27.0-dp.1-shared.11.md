**This release is for a prerelease version of mochiOS SDK. APIs may change before release.**

mochiOS SDK 27.0 dp.1 shared.11

* Added an ARM64 cross SDK with AAPCS64 process startup, newlib, compiler-rt builtins, libc++, libc++abi and libunwind.
* Added explicit CPU selection for the compiler, LLVM linker, CMake toolchain and SDK archive. Build outputs cannot be reused for a different CPU.
* Added ARM64 Variant-I TLS layout and native ELF relocation support to the process runtime.
* Fixed the generic newlib reentrant wall-clock entry point and the public native libc utsname layout.
* Added ARM64 C/C++ executable, shared-library and ELF checks. Full ARM64 mochiOS boot and application execution remain unverified.
